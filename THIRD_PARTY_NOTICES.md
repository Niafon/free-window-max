# Сторонние компоненты

Собственный код и учебные иллюстрации/данные проекта — MIT. Точные версии библиотек: package-lock.json. Оригинальные LICENSE файлов зависимостей сохраняются в node_modules при установке и в контейнере.

React, Vite, TypeScript, Fastify и плагины, Zod, Zustand, TanStack Query, Drizzle ORM, node-postgres, tsup/tsx и Vitest распространяются с открытыми лицензиями; итоговые SPDX сведения всех прямых зависимостей фиксируются в `docs/dependencies.json`. Lucide содержит собственную ISC-лицензию, Playwright — Apache-2.0. MAX UI и официальный MAX Bot SDK используются на условиях их пакетов; никакие исходные файлы их лицензий не удаляются.

Node.js и Docker base images содержат отдельные лицензии. PostgreSQL — PostgreSQL License, PostGIS — GPL-2.0-or-later, Caddy — Apache-2.0; они запускаются отдельными сервисами. При распространении изменённых образов соблюдайте соответствующие условия.

MAX, KudaGo и Яндекс — внешние сервисы, не включённые в MIT-лицензию проекта. Их названия служат для идентификации интеграций. Доступность API и разрешённое использование данных определяются условиями провайдеров, см. docs/data-sources.md.
