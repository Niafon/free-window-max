# Алгоритм

Дата: московское сегодня + 7 дней; свободное окно не более 12 часов. Приоритетный сценарий продукта — 1–4 часа после занятий.

Жёсткие ограничения применяются **до** рейтинга для каждого участника:

1. Известны цена и полное расписание; событие не sold_out; возраст и исключения соблюдены.
   Если выбраны интересы, событие должно относиться хотя бы к одному из них (в компании — к интересам хотя бы одного участника). Пустая выдача из-за интересов предлагает компромисс «Показать все категории». В реальном режиме маршруты считаются только для событий выбранных интересов.
2. Верхняя подтверждённая цена + указанная пользователем сумма проезда не больше бюджета.
3. Дорога туда и обратно по отдельности не превышает лимит.
4. Выход + дорога + 10 минут ≤ начало; конец + обратная дорога + 10 минут ≤ конец окна.
5. Для гибких демонстрационных занятий время сдвигается внутри заявленных часов работы с сохранением длительности. Для KudaGo длительность и часы не придумываются.

Рейтинг: `0.35 × интересы + 0.25 × дорога + 0.15 × цена + 0.15 × запас времени + 0.10 × полнота`. Контекст «спокойно/активно/свидание» задаёт мягкие предпочтения. Пустые интересы означают отсутствие фильтра; при нескольких выбранных интересах выше те события, что совпадают с большим их числом. Групповой рейтинг: `0.7 × среднее + 0.3 × минимальное`. Даже максимальный рейтинг не отменяет ограничения.

TOP 10, детерминированное сравнение при равенстве. Объяснения строятся из фактически проверенных цены, пути, возврата и интересов. Нейросеть/LLM не требуется.

При пустом результате отдельно пересчитываются ограниченные изменения бюджета, дороги и длительности окна. Предлагается только изменение с реальным положительным числом вариантов; исходные условия не меняются автоматически. Нет пересечения времени компании — отдельное объяснение.

Тесты `tests/engine.test.ts`: границы окна, возвращение, 10-минутный запас, бюджет/проезд, неизвестная цена, sold_out, возраст, интересы, групповые ограничения, компромиссы, сбой провайдера и разбор цен. Целевые показатели из ТЗ не подменяются измеренными.
