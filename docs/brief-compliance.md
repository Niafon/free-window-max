**Нельзя заявлять полную готовность к сдаче**, пока не закрыты привязка mini app в кабинете MAX, доступ проверяющих и закрытый служебный слайд. Эти внешние шаги не заменяются наличием Docker-файлов или красивым демо. Пользователь прямо отложил VPS; выдуманного домена или фиктивных результатов проверки нет.

Решения по расхождениям с DOCX: вместо serverless подготовлена VPS по указанию владельца; npm workspaces не нужны для одного приложения с общими пакетами, используется один lockfile; геолокация — браузерная с разрешением; LLM не включена, ручной сценарий полностью независим от неё. Бот использует тестовые данные для точек из списка и реальные для геопозиции; mini app по умолчанию работает на реальных данных, тестовые включаются вручную внизу страницы. Желаемые p95 и конверсия остаются целями до пилота.
